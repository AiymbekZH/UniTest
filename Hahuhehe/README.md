# Hahuhehe

Standalone UI prototype for the UniTest premium redesign.

This folder is intentionally isolated from the existing `client` app. It uses mock data and does not call the backend.

## Commands

```powershell
cd Hahuhehe
npm install
npm run dev
npm run build
```

## Screens Included

- Dashboard / home
- Test creator
- Test taking flow
- Arena / live game
- User profile
- Login / register
