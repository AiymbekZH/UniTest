# 🔐 Система ID для Активации Админ Прав

## Что это? 

Каждому пользователю при регистрации автоматически присваивается **уникальный 12-значный ID** (например: `SAL55GD18DFG`). Этот ID используется для активации админ прав.

---

## 📋 Как использовать?

### Шаг 1: Узнайте свой ID

1. Зайдите на сайт → **Профиль** (иконка в Navbar)
2. Найдите раздел **"Ваш уникальный ID"**
3. Скопируйте свой ID (нажмите на иконку копирования)

**Ваш ID выглядит так:** `A7FG2M9KB4P1`

---

### Шаг 2: Активируйте админ права

1. На странице **Профиля**, найдите раздел **"Активировать админ права"**
2. Нажмите **"+ Открыть форму"**
3. Введите **корректный ID** в поле
4. Нажмите **"Активировать админ"**

✅ Готово! Теперь у вас есть доступ к админ-панели

---

## 👑 Для Создателя (Владельца)

Если вы **создатель проекта**, выполните дополнительно шаг для получения специального ID `OWNERUNITEST`:

### Способ 1: Используя скрипт (Рекомендуется)

1. Откройте терминал в папке проекта:
   ```bash
   cd C:\Users\aiymb\OneDrive\Desktop\NewProjectTestOnline
   ```

2. Запустите команду:
   ```bash
   node change-my-id.js your-email@example.com OWNERUNITEST
   ```
   
   **Замените `your-email@example.com` на ваш реальный email**

3. Если всё успешно, вы увидите:
   ```
   ╔════════════════════════════════════╗
   ║     ID УСПЕШНО ИЗМЕНЁН ✅          ║
   ╠════════════════════════════════════╣
   ║ Пользователь: Ваше Имя
   ║ Email:        your-email@example.com
   ║ Старый ID:    ABC12DEF3GHI
   ║ Новый ID:     OWNERUNITEST
   ╚════════════════════════════════════╝
   ```

4. Теперь используйте этот ID для активации админ:
   - На странице Профиля введите: `OWNERUNITEST`
   - Нажмите "Активировать админ"

## 🔄 Можно ли изменить свой ID?

**Да!** Используйте скрипт выше:

```bash
node change-my-id.js your-email@example.com YOUR-NEW-ID
```

## ❓ FAQ

**Q: Забыл свой ID, как его узнать?**
A: Зайдите в Профиль на сайте — там показан ваш текущий ID

**Q: ID должен быть в ВЕРХНЕМ РЕГИСТРЕ?**
A: Неважно — система автоматически переводит в ВЕРХНИЙ РЕГИСТР

**Q: Что если удалить пользователя, а потом создать заново?**
A: Получит НОВЫЙ ID. Старый не восстановится.

**Q: Кто может быть админом?**
A: Любой пользователь, если знает/имеет корректный ID активации
