## 8. **Производительность**
- **⚡ Lazy loading** - Виртуализация длинных списков тестов/вопросов (react-window). Вместо рендера 1000 карточек — только видимые 10-20. Критично для масштабирования.
- **🖼️ Image optimization** - Конвертация base64 изображений в WebP на сервере, сжатие до разумного размера (sharp). Сейчас base64 хранится как есть — это раздувает MongoDB.
- **📦 Code splitting** - Разделить бандл на чанки по роутам (React.lazy + Suspense). Сейчас один чанк >500KB. Каждая страница грузится отдельно — быстрее первый запуск.
- **🗄️ Redis кэш** - Кэширование популярных тестов, лидербордов, статистики в Redis. Снижение нагрузки на MongoDB при большом трафике.

## 9. **Тестирование кода**
- **🧪 E2E тесты** - Playwright/Cypress для критических сценариев: регистрация → создание теста → прохождение → результат. Запуск в CI/CD перед деплоем.
