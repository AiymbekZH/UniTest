# 📋 UniTest — Все функции сайта

---

## 🔐 Аутентификация и пользователи

1. **Регистрация** — создание аккаунта с ФИО, email, пароль. Выбор роли: студент или учитель
2. **Вход** — по email и паролю, JWT-токен на 7 дней
3. **Уникальный ID** — каждому пользователю при регистрации генерируется 12-символьный ID (буквы + цифры)
4. **Роли** — три роли: `student`, `teacher`, `admin`. Разные права доступа
5. **Активация админа** — владелец платформы активирует админ-права через специальный маршрут с уникальным ID
6. **Бан пользователя** — админ может заблокировать аккаунт с указанием причины. Заблокированный не может войти
7. **Предупреждения** — админ может выдать пользователю предупреждение (warning) с текстом

---

## 👤 Профиль

8. **Просмотр профиля** — ФИО, email, роль, уникальный ID, дата регистрации
9. **Редактирование профиля** — изменение имени, фамилии, отчества
10. **Смена пароля** — с подтверждением нового пароля (валидация совпадения)
11. **Аватар** — загрузка аватарки (URL)
12. **Статистика профиля** — количество созданных и пройденных тестов, средний балл (агрегация на бэкенде)
13. **Выбор языка интерфейса** — переключение между 🇬🇧 English, 🇷🇺 Русский, 🇰🇿 Қазақша
14. **Публичный профиль** — другие пользователи могут просмотреть профиль по ID

---

## 📝 Создание тестов

15. **Редактор тестов** — полноценный конструктор с навигацией по вопросам, drag-and-drop
16. **6 типов вопросов:**
    - `single-choice` — один правильный ответ
    - `multiple-choice` — несколько правильных ответов
    - `true-false` — верно / неверно
    - `essay` — развёрнутый текстовый ответ
    - `matching` — сопоставление пар
    - `fill-blank` — вписать ответ
17. **Rich Text Editor** — форматирование текста вопроса: жирный, курсив, списки, ссылки, код
18. **Медиафайлы в вопросах** — загрузка изображений, видео и аудио к каждому вопросу
19. **Пассаж (текст для чтения)** — к вопросу можно прикрепить базовый текст/отрывок
20. **Объяснение ответа** — учитель может добавить explanation, который показывается после ответа
21. **Баллы за вопрос** — настраиваемое количество баллов для каждого вопроса (от 0)
22. **Теги** — добавление тегов к тесту для категоризации и поиска
23. **Автосохранение черновика** — тест автоматически сохраняется в localStorage при создании
24. **Импорт вопросов из CSV** — загрузка вопросов из табличного файла (CSV/TSV)
25. **Дублирование теста** — API для копирования существующего теста (с обнулением статистики)

---

## ⚙️ Настройки теста

26. **Таймер** — ограничение по времени (в минутах), 0 = без лимита
27. **Максимум попыток** — сколько раз можно пересдать тест
28. **Перемешивание вопросов** — случайный порядок вопросов при каждой попытке
29. **Перемешивание ответов** — случайный порядок вариантов ответов
30. **Показ результатов** — включить/выключить показ правильных ответов после сдачи
31. **Мгновенная обратная связь** — проверка ответа сразу после выбора (зелёный/красный)
32. **Тренировочный режим** — неограниченные попытки, результаты не сохраняются
33. **Частичные баллы** — за частично правильные ответы в multiple-choice и matching
34. **Публичный/приватный тест** — публичный виден всем, приватный — только по ссылке
35. **Дата начала и окончания** — авто-открытие и закрытие теста по расписанию
36. **Таймаут бездействия** — автозавершение теста если студент неактивен N минут
37. **Пул вопросов** — из банка в N вопросов случайно выбирается M для каждого студента
38. **Комментарии** — разрешить/запретить комментарии к тесту

### Анти-чит система:
39. **Блокировка переключения вкладок** — фиксация нарушений при уходе из вкладки
40. **Блокировка копирования/вставки** — Ctrl+C и Ctrl+V заблокированы
41. **Блокировка скриншотов** — попытка скриншота фиксируется
42. **Максимум нарушений** — автозавершение теста при превышении лимита (по умолчанию 5)
43. **Лог нарушений** — каждое нарушение с типом и временем сохраняется в результате

---

## 🎫 Система вариантов (билетов)

44. **Включение вариантов** — учитель задаёт количество билетов (например, 30)
45. **Захват билета** — в приватном тесте каждый студент берёт свой уникальный вариант (один на одного)
46. **Публичные варианты** — в публичном тесте все варианты доступны для всех
47. **Детерминированная перетасовка** — вопросы перемешиваются одинаково для одного и того же номера варианта (seeded shuffle)
48. **Сброс билетов** — учитель может обнулить все занятые билеты

---

## 📖 Банк вопросов

49. **Сохранение вопросов в банк** — учитель может сохранить вопросы теста в персональный банк
50. **Просмотр банка** — список всех сохранённых вопросов с фильтрацией по категории и типу
51. **Добавление из банка** — вставить вопросы из банка в новый тест
52. **Массовое сохранение** — все вопросы теста одной кнопкой попадают в банк

---

## 🤖 AI-генерация вопросов

53. **Генерация из текста** — вставить текст → AI создаёт вопросы по нему
54. **Генерация из файла** — загрузить PDF, DOCX или TXT → AI извлекает контент и создаёт вопросы
55. **Настройка количества** — выбрать сколько вопросов сгенерировать
56. **Выбор типов вопросов** — single-choice, multiple-choice, true-false, fill-blank, essay
57. **Превью и редактирование** — сгенерированные вопросы можно просмотреть и отредактировать перед добавлением
58. **История генераций** — все предыдущие AI-генерации сохраняются на сервере (не в localStorage)
59. **Удаление записей истории** — удалить одну или очистить всю историю

---

## 📝 Прохождение теста

60. **Доступ по ссылке** — тест открывается по уникальной share-ссылке
61. **Гостевой доступ** — тест можно пройти без регистрации (ввод имени)
62. **Таймер обратного отсчёта** — визуальный таймер с минутами и секундами
63. **Навигация по вопросам** — кнопки "Назад"/"Вперёд" + сетка номеров вопросов
64. **Индикатор прогресса** — отмечает отвеченные/пропущенные вопросы цветами
65. **Кнопка "Отметить"** — пометить вопрос для повторного просмотра
66. **Проверка ответа (instant feedback)** — немедленная проверка с анимацией верно/неверно
67. **Matching — drag-and-drop** — перетаскивание для сопоставления пар
68. **Автозавершение** — тест завершается при истечении таймера или превышении нарушений
69. **Подтверждение завершения** — модальное окно "Вы уверены?" при нажатии "Завершить"
70. **Запись нарушений в реальном времени** — нарушения отправляются на сервер по мере возникновения
71. **Сохранение прогресса** — промежуточные ответы сохраняются (in-progress → completed)

## 📊 Результаты

72. **Страница результата** — детальный разбор: общий балл, процент, время, диаграмма
73. **Кольцо прогресса (SVG)** — визуализация процента правильных ответов
74. **Stacked bar** — горизонтальная полоса: зелёное (верно) / красное (неверно) / серое (пропущено)
75. **Разбор каждого вопроса** — показывает вопрос, выбранный ответ, правильный ответ, explanation
76. **Рейтинг теста** — после прохождения студент может оценить тест от 1 до 5 звёзд
77. **Мои результаты** — список всех пройденных тестов с датой, баллом и процентом
78. **Сертификат** — скачать PDF-сертификат за прохождение теста
79. **Поделиться результатом** — скопировать ссылку на результат

## 📈 Аналитика для учителя

80. **Список результатов по тесту** — таблица всех прошедших: ФИО, балл, процент, время, нарушения
81. **Оценка эссе** — ручная проверка эссе-ответов: учитель ставит баллы и пишет feedback
82. **Аналитика по вопросам (API)** — процент правильных ответов на каждый вопрос, популярность каждого варианта
83. **Средний балл теста** — автоматически обновляется после каждого прохождения
84. **Счётчик попыток** — сколько всего раз пройден тест
85. **Email-уведомление** — учитель получает email когда студент завершает тест (при настроенном SMTP)

## 🏆 Лидерборд

86. **Публичная таблица лидеров** — топ-100 по каждому тесту, сортировка по баллу и времени
87. **Дедупликация** — если студент проходил несколько раз — в таблице только лучший результат
88. **Подиум** — топ-3 с аватарками и анимацией
89. **Поддержка гостей** — гости тоже попадают в лидерборд (по имени)

## 👥 Группы

90. **Создание группы** — название, описание, автоматический invite-код
91. **Присоединение по коду** — студент вводит 8-символьный код → попадает в группу
92. **Список участников** — ФИО, email, аватар, дата вступления
93. **Назначение тестов** — учитель привязывает тесты к группе с дедлайном
94. **Удаление тестов из группы** — убрать назначенный тест
95. **Удаление участников** — учитель может кикнуть участника
96. **Выход из группы** — участник может покинуть группу
97. **Регенерация кода** — сбросить invite-код (старый перестаёт работать)
98. **Soft delete** — удалённая группа не удаляется из БД, а помечается как `isDeleted`

## 🔧 Техническое

126. **Rate Limiting** — защита API от DDoS (500 запросов / 15 минут на IP)
127. **Хеширование паролей** — bcrypt с salt rounds = 12
128. **JWT-аутентификация** — Bearer-токены, middleware для protected routes
129. **Optional Auth** — маршруты, работающие и для авторизованных, и для гостей
130. **Индексация MongoDB** — индексы на `creator`, `shareLink`, `test+user+status`, `inviteCode`
131. **Docker** — Dockerfile для деплоя (single-stage, node:20-slim)
132. **DigitalOcean App Platform** — хостинг на Digital Ocean с автодеплоем из GitHub
133. **3 языка** — полная локализация EN / RU / KZ
