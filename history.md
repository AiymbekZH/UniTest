## Старт: задачи из `problems.md`

Изначально были поставлены такие задачи:

1. Исправить обложки тестов в dashboard, чтобы они были ровными и пропорциональными.
2. Переделать и улучшить функцию мультиперевода.
3. Исправить мобильный баг, где при вводе на других языках ломался UI / сворачивалась клавиатура.
4. Переделать систему доступа к AI через админку:
   - убрать доступ у существующих аккаунтов
   - дать админу возможность выдавать и снимать доступ
   - показывать понятный фидбек пользователям без доступа

Что сделано:
- переделан overlay текста на баннере
- убраны конфликтующие подписи и дублирующиеся caption-слои
- поправлен mobile layout create/edit test
- confirm modal вынесен из layout navbar, чтобы он центрировался стабильно
- переключение аккаунта переведено на автоматический reload
- добавлено скрытие/показ блока баннера
- баннер выведен в стартовом окне теста
