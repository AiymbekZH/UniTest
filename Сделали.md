Привет! Вот текущий статус моего проекта UniTest (Fullstack-приложение для прохождения тестов по истории Казахстана, английскому и т.д.). Запомни этот контекст для дальнейшей работы:

1. ИНФРАСТРУКТУРА И ДЕПЛОЙ:
- Проект успешно задеплоен на DigitalOcean App Platform (Production).
- База данных: облачная MongoDB Atlas (успешно подключена через MONGODB_URI).
- Настроен CI/CD: при пуше в ветку main на GitHub (git push origin main), DigitalOcean автоматически подтягивает изменения и обновляет боевой сервер. Мне больше не нужно настраивать сервер вручную.
- Рабочий порт бэкенда: 5003.

2. ТЕКУЩАЯ ПРОБЛЕМА И ЗАДАЧА:
- В проекте есть (или планируется) функция автоматической генерации тестов с помощью ИИ.
- Изначально мы хотели использовать Azure OpenAI (GPT-4), но столкнулись с жесткими ограничениями по квотам для новых аккаунтов. 
- МЫ ПОЛНОСТЬЮ ОТКАЗЫВАЕМСЯ ОТ AZURE И OPENAI для этой задачи.
