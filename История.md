## 1. Что такое UniTest

**UniTest** — это full-stack платформа для онлайн-тестирования. Преподаватели создают тесты, студенты их проходят, система автоматически проверяет и выдаёт результаты. Развёрнута на **Fly.io**, домен: `unitest.app`.

## 7. Ключевые фичи (реализованные)

### 7.1 ИИ-генерация вопросов
- Маршрут: `POST /api/ai/generate`
- Используется OpenAI GPT (SDK `openai`)
- Параметр `max_completion_tokens` (не `max_tokens`) для GPT-5.2+
- Есть история генераций

### 7.2 Билетная система (Tickets/Variants)
- Тест можно разбить на билеты — каждый студент получает случайный набор вопросов
- Модель `TicketClaim.js` отслеживает кто какой билет получил
- Поддержка приватного доступа (по коду/Guest ID) и публичного

### 7.3 Античит
- Хук `useAntiCheat.js` в `client/src/hooks/`
- Отслеживание: смена вкладок (visibilitychange), copy-paste блокировка
- Данные сохраняются в результате

### 7.4 Система оценивания
- **Partial credit** — частичные баллы за множественный выбор и matching
- Если из 4 правильных студент выбрал 3 → получает 75% баллов
- Variant-based scoring — разные баллы за разные варианты ответов

### 7.5 Мультиязычность
- 3 языка: казахский, русский, английский
- Переключение через `LanguageContext`

### 7.6 Guest-режим
- Прохождение тестов без регистрации через `guestId` (UUID)
- Результаты привязываются к guestId

### 7.7 Комментарии и уведомления
- Комментарии к тестам
- Система уведомлений (колокольчик)

## 8. Деплой

### DigitalOcean (App Platform)
- Деплой: автоматически через **GitHub push** (CI/CD)
- При пуше в main-ветку DigitalOcean сам пересобирает и деплоит приложение
- Домен: `unitest.app`
- Порт: `8080`

### Процесс деплоя
1. `cd client && npm run build` — собрать фронтенд в `client/dist/`
2. `git add . && git commit && git push` — пуш в GitHub
3. DigitalOcean автоматически подхватывает и деплоит

> **Примечание**: в репозитории есть `fly.toml` — это артефакт от старой попытки деплоя на Fly.io. Сейчас НЕ используется. Актуальный деплой — DigitalOcean.

### Переменные окружения (на DigitalOcean)
- `MONGODB_URI` — строка подключения к MongoDB Atlas
- `JWT_SECRET` — секрет для JWT
- `OPENAI_API_KEY` — ключ OpenAI для ИИ-генерации
- `SMTP_*` — настройки для nodemailer

```

│   ├── Demo.jsx         — 3 шага (Создай → Решай → Анализируй) с мини-превью
│   ├── Stats.jsx        — Анимированные счётчики (12500+ тестов, 48000+ студентов, 350000+ результатов, 99%)
│   ├── Reviews.jsx      — Отзывы в БЕСКОНЕЧНОМ MARQUEE (2 ряда, противоположные направления)
│   ├── CTA.jsx          — Призыв к действию с параллакс-кольцами
│   └── Footer.jsx       — Футер со ссылками

    ├── useParallax.js   — Хук для scrollY и scroll progress
    └── useTilt.js       — 3D tilt + spotlight эффект для карточек
```

### Ключевые CSS-эффекты (`index.css`)
- **Aurora** — плавающие размытые цветовые пятна (`aurora-1`, `aurora-2`, `aurora-3`)
- **Glassmorphism** — `.glass` с `backdrop-blur(20px)`
- **Gradient text** — анимированный градиент на тексте
- **Marquee** — бесконечная прокрутка `@keyframes marquee`
- **Spotlight** — подсветка на карточке следующая за курсором (CSS vars `--mouse-x`, `--mouse-y`)
- **Float** — `float-slow`, `float-slow-delay`, `float-slow-delay-2` для декоративных элементов
- **Noise** — SVG шум-текстура поверх всего

### Дизайн
- Тема: **тёмный космос** (`--color-surface: #050a18`)
- Цвета: индиго → фиолетовый → розовый градиенты
- Шрифт: Inter (Google Fonts)
- Параллакс реализован через `framer-motion` `useScroll` + `useTransform`

### Запуск
```bash
cd landing
npm install
npm run dev        # или: npx vite --host --port 4321
```

## 12. Что нужно знать новому ИИ-агенту

1. **Монорепозиторий**: `client/` и `server/` — основной проект, `landing/` — отдельный лендинг
2. **API**: все запросы через `/api/*`, сервер и клиент раздаются с одного порта (8080)
3. **Auth**: JWT в localStorage (`unitest_token`), роли: student/teacher/admin
4. **DB**: MongoDB Atlas, Mongoose ODM
5. **Деплой**: DigitalOcean App Platform, автодеплой через `git push` в GitHub. Перед пушем: `cd client && npm run build`
6. **Landing**: запускается отдельно (`cd landing && npm run dev`), не связан с основным приложением
7. **Стили клиента**: Tailwind v3 with `tailwind.config.js`, тёмная/светлая тема через `ThemeContext`
8. **Стили лендинга**: Tailwind v4 through `@tailwindcss/vite`, только тёмная тема
